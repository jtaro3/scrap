# Scrap マップエディター

エディター版: 0.2.11

open-editor.cmdで42px素材一覧を更新して起動します。

- maps/tiles: grass.png、flowers.png、path.png、water.png、bridge.png（各42×42px）
- maps/object: rock.png（42×42px）、tree.png（42×84px）
- 42pxの倍数ではない旧素材はフォルダに残り、パレットには登録されません。
- カメラ表示範囲の枠と表示画面サイズの設定は削除しました。グリッド・編集倍率は使用できます。
- 初期マップは20×20マス。編集盤面は42×21pxの上面でつなぐクォータービューです。ゲームへの読み込み連動は未実装です。
- 保存はScrap専用のブラウザー保存領域です。JSON書き出し名はscrap-map.jsonです。
- プレイヤー確認画像はScrapのidle.pngから作成しています。
- 親フォルダのgame-data.jsonがある場合はマスター設定を取り込みます。

## 0.2.0 — 2026-10-05

42pxチップの取り込み・配置・グリッド・通行不可枠を42pxへ変更。カメラ表示範囲を削除。ゲーム別の保存領域を設定。

## 0.2.1 — 2026-10-05

盤面・グリッド・クリック位置・通行不可枠・プレイヤーをクォータービューへ変更。水面は地面より21px下げて描画。マス数変更と保存形式を維持。

## 0.2.2 — 2026-10-05

視点ボタンでクォータービューと真上を切り替え。同じマップ・マス数・倍率・編集ツールを使用。真上では地面の上面を正方形へ投影し、オブジェクトは識別用の既存画像で表示。

## 0.2.3 — 2026-10-05

3つの視点を独立ボタンで表示。平面は42×42pxのチップ全体を正方形に並べて上面・側面を確認。高さの配置差はクォータービューで確認。各視点で同じマップの編集が可能。

## 0.2.4 — 2026-10-05

横から高さを確認する閲覧用側面表示へ変更。クォータービューは左右45度ずつ8方向に回転。回転後も地面の配置座標を逆変換。木・岩の画像は既存方向のまま表示。

## 0.2.5 — 2026-10-05

編集・確認タブを追加。編集はクォータービュー、確認は真上で開始し確認中の描画を抑止。黄色の左右回転、角度リセット、選択視点の点滅を追加。動きを減らす設定では点滅を省略。

## 0.2.6 — 2026-10-05

編集マップと確認マップを同一画面へ配置。確認は真上表示から開始し編集内容をリアルタイム反映。チップ一覧はマップ下へ移動。スマホでは編集・確認の順に縦並び。ゲームのJSON読み込みは未実装。

## 0.2.7 — 2026-10-05

編集と確認を2:1で配置。ツールとチップ一覧を縮小し、保存操作を横並びに整理。初期倍率を編集領域の幅から選択。スマホでは編集・チップ・確認の順に配置。

## 0.2.8 — 2026-10-05

チップ一覧を固定高の縦スクロール領域に変更。右端に幅16pxのスクロールバーを常時表示。PC240px、スマホ220pxの一覧高。

## 0.2.9 — 2026-10-05

描画ツールをチップ一覧の直上へ移動。ツールと素材を同じ下部パネルへまとめる。

## 0.2.10 — 2026-10-05

file://直接起動時の確認マップ同期を修正。送信先をファイル起動に対応し、受信は親ウィンドウを厳密に確認。確認側の準備完了通知で初期同期を再送。

## 0.2.11 — 2026-10-05

確認用iframeとページ間通信を廃止。同一ページの同じmapデータを2つのcanvasへ描画。地面・オブジェクト・サイズ変更の即時反映。
