# Scrap マップエディター

エディター版: 0.2.0

open-editor.cmdで42px素材一覧を更新して起動します。

- maps/tiles: grass.png、flowers.png、path.png、water.png、bridge.png（各42×42px）
- maps/object: rock.png（42×42px）、tree.png（42×84px）
- 42pxの倍数ではない旧素材はフォルダに残り、パレットには登録されません。
- カメラ表示範囲の枠と表示画面サイズの設定は削除しました。グリッド・編集倍率は使用できます。
- 初期マップは20×20マス。現在の編集盤面は正方形グリッドです。ゲームのクォータービュー投影と読み込み連動は未実装です。
- 保存はScrap専用のブラウザー保存領域です。JSON書き出し名はscrap-map.jsonです。
- プレイヤー確認画像はScrapのidle.pngから作成しています。
- 親フォルダのgame-data.jsonがある場合はマスター設定を取り込みます。

## 0.2.0 — 2026-10-05

42pxチップの取り込み・配置・グリッド・通行不可枠を42pxへ変更。カメラ表示範囲を削除。ゲーム別の保存領域を設定。
