# SCRAPBOUND / スクラップ

スマホのブラウザーで遊べる、Canvas 2Dのクォータービューゲーム。

## 現在の機能

- 42×42pxの仮マップチップ（上面は42×21pxの菱形）
- 草地・川・崖・橋・木の配置
- 矢印／WASD／画面ボタンによる移動
- E／「拾う」によるスクラップ回収
- 一時停止、マス境界の表示切り替え、チップ画像保存

## 編集・ビルド

ルートの `index.html` と `game.js` を編集します。Node.jsで次を実行すると、キャッシュ対策用のハッシュ付きJavaScriptを含む `dist` を生成します。

```sh
node build-static.mjs
```

ブラウザーではルートの `index.html`、公開時は `dist/index.html` を使用します。公開用には `play.html` と `play-2.html` も生成します。
