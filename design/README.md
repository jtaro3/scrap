# Scrap デザイン素材

素材版: 1.0.0 / 元のゲーム版: 0.1.1

現在のゲームのCanvas描画を透過PNGとして書き出した素材です。ゲーム本体は引き続きgame.jsの描画処理を使います。PNGを編集してもゲーム表示は自動では変わりません。エディターへの登録もまだ行っていません。

|場所|内容|サイズ|
|---|---|---|
|tiles/|草地・花・道・水・橋の5種類。崖の側面を含む|各42×42px|
|objects/tree.png|木と影|42×84px|
|objects/rock.png|岩|42×42px|
|items/scrap.png|回収アイテムと足元のリング|42×42px|
|player/idle.png|待機中のプレイヤーと影|42×63px|
|player/walk-1.png〜walk-4.png|現在の上下動を4等分した歩行サンプル|各42×63px|
|tileset.png|チップ5枚を横に並べた画像|210×42px|
|preview.png|名前付きの全素材一覧|確認用|
|palette.json|ゲーム描画コード内の色一覧|JSON|
|manifest.json|寸法・描画基準点・画像ハッシュ・元ソースのハッシュ|JSON|

地面の上面は42×21pxの菱形です。木とプレイヤーは上方向にはみ出すため、画像の高さを大きくしています。配置位置はmanifest.jsonのanchor（画像左上からのpx）で合わせます。

歩行は上下動のみで、方向別の絵や手足のアニメーションは現在のゲームにはありません。待機・歩行の一部は同じ見た目になります。

UIのボタンやパネル、グリッドはHTML/CSS/Canvasの図形です。独立した画像素材ではなく、index.htmlとgame.jsが元データです。

## 再生成

Node.jsと @napi-rs/canvas が必要です。ゲームのリポジトリで以下を実行します。

```sh
npm install --no-save @napi-rs/canvas
node tools/export-design.cjs
```

生成対象のPNG・一覧・JSONを上書きします。画像を手作業で編集した場合は再生成前に別名で保管してください。game.jsの描画構造が変わった場合は生成スクリプトも調整が必要です。

ブラウザーとPNG生成ライブラリでは、図形の縁のアンチエイリアスに微差が出る場合があります。
